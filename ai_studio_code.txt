# TASK: Integrate TimeWall Surveys & Offers into RevaMine Hybrid Mobile App

You are tasked with integrating **TimeWall Surveys & Offers** into the RevaMine Hybrid Mobile App (Flutter / React Native / Capacitor / Ionic) with **100% database, authentication, and balance parity** with the RevaMine web and backend ecosystem.

---

### 1. Architectural Overview & Security Rules

1. **User Identity Parameter**:
   - Always use the authenticated Firebase Auth User UID (`auth.currentUser.uid`) as the user identifier (`userId` / `uid`).
   - **NEVER** generate random session IDs or pass email addresses as `userId`.

2. **Zero-Loss 72-Hour Survey Security Escrow**:
   - TimeWall survey rewards are placed into a **72-hour anti-fraud security hold** by our backend webhook (`/api/timewall-postback`).
   - When viewing or updating the user's balance:
     - `pointsBalance` (number) = **Withdrawable Balance**. User can ONLY redeem up to this amount.
     - `pendingSurveyBalance` (number) = **72-Hour Escrow Hold**. Survey points waiting for the fraud review window to clear.
   - ⚠️ **CRITICAL REDEMPTION VALIDATION**:
     ```typescript
     // CORRECT:
     if (requestedPoints > user.pointsBalance) {
       showToast("Insufficient withdrawable balance. Some points are in 72h hold.");
       return;
     }
     
     // STRICTLY FORBIDDEN:
     // if (requestedPoints > user.pointsBalance + user.pendingSurveyBalance) { ... }
     ```

3. **Backend Host URLs**:
   - **Primary API Base URL**: `https://api.revamine.com`
   - **Fallback Base URL**: `https://revamine.com`

---

### 2. Implementation Approach: Dual Options

You can implement either or both of the following experiences in the mobile app:

#### Option A: Native Survey Cards (Recommended UI)
Fetch curated survey cards from our proxy endpoint and render high-conversion native cards inside the app.

- **Endpoint**: `GET https://api.revamine.com/api/timewall/surveys`
- **Query Parameters**:
  - `userId` (required): Firebase Auth UID (`auth.currentUser.uid`)
  - `screen_width` (optional): Device screen width (e.g. `390`)
  - `screen_height` (optional): Device screen height (e.g. `844`)
- **Sample Request**:
  ```http
  GET https://api.revamine.com/api/timewall/surveys?userId=USER_FIREBASE_UID&screen_width=390&screen_height=844
  Accept: application/json
